🚀 Upstream Contribution: Supabase Storage PR #1616
Target: supabase/storage

An open contribution to the core Supabase Storage engine (PR #1616: fix(file): honor upload cancellation signals).

// Unpatched upstream (supabase/storage v1.84.32): FileBackend.uploadObject received `signal: AbortSignal` but never bound it to Node's stream pipeline: await ensureFile(stagedFile) await pipeline(body, fs.createWriteStream(stagedFile)) Consequences: 1. Pre-aborted calls proceeded to write files and returned 200 OK. 2. Active client disconnects continued streaming to disk. 3. Leftover temporary files were orphaned.
// Verified Patch (PR #1616 by Philippe Godfroy): if (signal?.aborted) { throw ERRORS.Aborted('Upload was aborted') } await ensureFile(stagedFile) await pipeline(body, fs.createWriteStream(stagedFile), { signal }) catch (err: unknown) { await fsp.unlink(stagedFile).catch(() => {}) if (err instanceof Error && err.name === 'AbortError') { throw ERRORS.AbortedTerminate('Upload was aborted', err) } } Regression Suite: 5/5 Passing Tests
